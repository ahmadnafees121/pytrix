How the code works

These are the real functions running on the Python backend.

def check_voting(age):
    if age < 0:
        return "Age cannot be negative."
    elif age >= 18:
        return "Eligible to vote."
    else:
        return f"Not eligible yet. Wait {18 - age} more year(s)."

def get_grade(marks):
    if marks >= 90:
        return "A"
    elif marks >= 75:
        return "B"
    elif marks >= 60:
        return "C"
    elif marks >= 40:
        return "D"
    else:
        return "F"
