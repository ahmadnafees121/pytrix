About Smart Python Lab

A small teaching project for two beginner Python topics. Every answer you see is produced by real Python code running on a Flask server, and the decision steps are shown to you.

What is covered

  • Input — reading values from a form, converting them with int() and validating them before use.
  • Output — building readable results with f-strings and print()-style console lines.
  • Conditionals — if, elif and else, chained decisions and nested checks.
  • Traceability — each response carries the list of conditions that were checked, so the flow is visible.

How it is built

  • Backend — Flask routes in app.py return JSON.
  • Frontend — plain HTML, CSS and vanilla JavaScript. No framework, no build step.
  • Templates — Jinja2 templates share one base.html layout.
  • Hosting — the same app.py runs as a Vercel Function; public/ is served from the CDN.
